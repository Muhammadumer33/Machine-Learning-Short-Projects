# 🧠 ML Mini Projects Collection by muhammadumer33

Welcome to the **Machine Learning Mini Projects Repository**!  
This collection of projects demonstrates real-world applications of machine learning using datasets from various domains like real estate, education, sonar signals, and healthcare.

Each project includes:
- A **clean dataset**
- A **Streamlit-based app** or notebook
- A **trained model**
- **Prediction interface** (where applicable)

---

## 🔗 Projects Included

### 🚗 Car Price Prediction
**Goal:** Predict the price of a car based on features like age, mileage, fuel type, etc.  
**Tech Stack:** Python, Scikit-learn, Streamlit  
📂 `Car Price Prediction/`

---

### 🔢 Digits Prediction (MNIST)
**Goal:** Predict hand-written digits using a classifier trained on MNIST dataset.  
**Tech Stack:** Python, Scikit-learn, Jupyter Notebook  
📂 `Digits Prediction/`

---

### 🏠 House Area Price Prediction
**Goal:** Predict house price based on area in square feet.  
**Tech Stack:** Linear Regression  
📂 `House area Prediction/`

---

### 🌊 Sonar Rock vs Mine Classification
**Goal:** Classify whether the object is a rock or a mine based on sonar data.  
**Tech Stack:** Logistic Regression, Pandas, Scikit-learn  
📂 `Sonar Rock VS Mine Prediction/`

---

### 🎓 Students Performance Analysis
**Goal:** Analyze and visualize student performance data across various subjects and demographics.  
**Tech Stack:** Python, Matplotlib, Seaborn  
📂 `Students Performance/`

---

### 💍 World Marriage Data Insights
**Goal:** Explore and visualize global marriage trends.  
**Tech Stack:** Python, Pandas, Plotly  
📂 `World Marriage/`
